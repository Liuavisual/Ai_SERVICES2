## 4. Redis优化

键命名规范: `delta:{模块}:{业务标识}:{ID}`

| 键模式 | 数据类型 | TTL | 用途 |
|--------|----------|-----|------|
| delta:config:ai:{key} | HASH | 3600s | AI配置缓存 |
| delta:session:user:{id} | STRING | 1800s | 用户会话 |
| delta:chat:history:{id} | ZSET | 86400s | 对话历史 |
| delta:keyword:rules | HASH | 3600s | 关键词规则 |
| delta:token:blacklist:{token} | STRING | Token有效期 | 黑名单 |
