## 二、测试中发现并修复的问题

### 问题1: `ai_personality_config` 表缺失
- **现象**: GET /api/v1/personality/configs 返回 500
- **原因**: 实体 `AiPersonalityConfig` 映射到表 `ai_personality_config`，但该表在数据库中不存在
- **修复**: 创建表结构（23个字段），插入3条测试配置数据
- **验证**: ✅ 修复后API正常返回3条配置记录

### 问题2: `customer_order_record` 表字段缺失
- **现象**: GET /api/v1/customer-profiles/orders/page 返回 500
- **原因**: 18个核心字段标记为 @TableField(exist = false)
- **修复**: 添加18个缺失列，删除 @TableField(exist = false) 注解
- **验证**: ✅ 修复后API正常返回33条消费记录
