## 二、测试中发现并修复的问题

### 问题1: `ai_personality_config` 表缺失
- **现象**: GET /api/v1/personality/configs 返回 500
- **原因**: 实体 `AiPersonalityConfig` 映射到表 `ai_personality_config`，但该表在数据库中不存在（DDL未执行）
- **修复**: 创建表结构（23个字段），插入3条测试配置数据
- **验证**: ✅ 修复后API正常返回3条配置记录

### 问题2: `customer_order_record` 表字段缺失
- **现象**: GET /api/v1/customer-profiles/orders/page 返回 500
- **原因**: `CustomerOrderRecord` 实体中18个核心字段标记为 `@TableField(exist = false)`，但 Service 层的 LambdaQueryWrapper 尝试使用这些字段作为查询条件，MyBatis-Plus 抛出异常
- **修复**: 
  - 向 `customer_order_record` 表添加18个缺失列（user_id, companion_id, order_type, order_time, amount, game_type, status, rating等）
  - 删除实体中18处 `@TableField(exist = false)` 注解
  - 重新编译 `delta-common` 模块并安装到本地Maven仓库
- **验证**: ✅ 修复后API正常返回33条消费记录

### 问题3: 前端路由路径不匹配（历史修复）
- **现象**: 菜单点击无反应或路由不正确
- **原因**: MainLayout.vue中菜单路径与router/index.js中路由定义不一致
- **修复**: 统一所有菜单路径和路由路径（已完成，本次验证通过）

### 问题4: 权限表数据重复（历史修复）
- **现象**: sys_permission表140行（应为35行），sys_role表12行（应为3行）
- **修复**: 备份后去重，保留备份表 bak_20260507_*
- **验证**: ✅ 当前权限数据正确（35条权限，3个角色）

### 问题5: customer_profile表缺少列（历史修复）
- **现象**: 客户生命周期API返回500
- **修复**: 添加 game_preferences, spending_level, assigned_cs_user_id 列
- **验证**: ✅ 当前表结构完整（48个字段）
